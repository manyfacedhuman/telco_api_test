# Telecom API Testing Framework

## Project Overview

This project demonstrates API testing concepts using a telecom customer lifecycle scenario.

The objective is to validate customer management APIs including:

- Create Customer
- Get Customer Details
- Update Customer Profile
- Disconnect Customer Service

## Tools Used

- Postman
- REST API Testing
- GitHub
- JSON
- Telecom Domain Knowledge

## Test Scenarios Covered

### Customer Lifecycle

1. Create Customer
2. Retrieve Customer Details
3. Update Customer Information
4. Disconnect Customer Service

### Validations

- Status Code Validation
- Response Body Validation
- Response Time Validation
- Data Integrity Checks
